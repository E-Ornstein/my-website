Engineering Projects

Exoskeleton Power Housing Unit

Designed the Power Housing Unit for Waterloo's first exoskeleton in the Applied Collegiate Exoskeleton Competition. Integrated removable battery packs, battery management system, wire routing, circuit board mounts, and cooling fans into a compact layout. Engineered and validated PCBs by designing and simulating circuits in Altium and LTSpice.

Automated Air Hockey Defense Machine

Built an autonomous air-hockey defense system to return incoming pucks, achieving a 76% successful deflection rate. Adapted design to strict component constraints using VEX IQ parts only. Designed a custom two-axis positioning system using gear-reduced belt drive for lateral motion and motor-driven linear actuator for rapid striking action. Collaborated with software team on C++ control integration for real-time tracking and response.

Discrete Transistor Fuzz Face Guitar Pedal

Designed and built an analog distortion pedal using discrete NPN BJTs, adjusting resistor values to set transistor bias points and achieve stable amplification and clipping behavior. Iteratively refined circuit behavior through empirical testing and component-level modifications.
